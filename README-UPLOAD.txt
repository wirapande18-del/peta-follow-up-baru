PETA FOLLOW UP - VERSI MULTI HEADER

Isi ZIP:
- index.html

Cara pakai:
1. Extract ZIP.
2. Upload index.html ke root repository GitHub peta-follow-up-baru.
3. Ganti/overwrite index.html lama.
4. Commit changes.
5. Tunggu Vercel deploy otomatis.
6. Buka peta-follow-up-baru.vercel.app dan coba Upload Bulanan.

Perubahan hanya pada upload Excel:
POLICE_NO, CUSTOMER, MODEL, VIN, SERVICE_ADVISOR, TELEPHONE_CP, RANGKA, ADDRESS.
Header bisa berada pada beberapa baris awal dan punya beberapa variasi nama.
Kolom Excel lain diabaikan.

Catatan:
Versi ini memuat source aplikasi stabil dari commit sebelumnya lalu menerapkan patch multi-header saat halaman dibuka.
Repository harus tetap public agar source stabil tersebut dapat dibaca.
