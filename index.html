Upload Data Bulanan

Header Excel sangat fleksibel. File tetap bisa di-upload selama aplikasi menemukan minimal 1 dari 6 field: POLICE NO, MODEL, CUSTOMER, ADDRESS/ALAMAT, TELEPHONE CP, atau SERVICE ADVISOR. Field yang tidak ada akan dibiarkan kosong dan kolom lainnya diabaikan.

Persiapan database diperlukan.
Jalankan file SUPABASE-MIGRATION-V6.sql satu kali di Supabase SQL Editor sebelum upload TGB / CR-7. Data lama tidak dihapus dan otomatis dianggap Service Berkala.

YTD = satu program berisi data kumulatif sampai periode yang dipilih. Riwayat follow up tidak otomatis ditimpa ketika pelanggan muncul kembali.

Tanggal ini menjadi periode data upload (tanggal/bulan/tahun) dan dipakai juga untuk filter, download, serta hapus data.
